# 🔮 관계 역할 타로 방 (Relationship Role Tarot Room)

당신은 그 사람에게 어떤 존재인가요? 12가지 관계 역할 메타포로 알아보세요.

## 🌟 Features

- **방 생성**: 질문을 입력하고 공유 가능한 방 생성
- **카드 선택**: 12가지 관계 역할 메타포 카드 중 선택
- **AI 해석**: LLM을 통한 2인칭 관계 역할 해석
- **공유**: 링크를 통해 여러 사람과 공유
- **호스트 기능**: 방 삭제 및 카드 숨기기
- **자동 만료**: 7일 후 자동 만료

## 🎴 12가지 카드

안전기지, 도화선, 거울, 배터리, 네비, 방패, 개그담당, 솔직봇, 거리두기, 썸온도, 멘토, 라이벌

## 🚀 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Database**: PostgreSQL + Prisma ORM
- **LLM**: Hugging Face Inference API (with OpenAI fallback)
- **Deployment**: Railway

## 📦 Installation

### Prerequisites

- Node.js 18+ and npm
- PostgreSQL database

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/woongiiit/tarot-room-poc.git
cd tarot-room-poc
```

2. Install dependencies:
```bash
npm install
```

3. Set up environment variables:
```bash
cp .env.example .env
```

Edit `.env` with your configuration:
```env
DATABASE_URL="postgresql://user:password@localhost:5432/tarot_room"
HUGGINGFACE_TOKEN="your_huggingface_token_here"
NEXT_PUBLIC_BASE_URL="http://localhost:3000"
```

4. Set up the database:
```bash
npx prisma migrate dev
```

This will create and apply migrations, and generate the Prisma Client.

5. Run the development server:
```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000)

## 🚂 Railway Deployment

### Step 1: Create Railway Project

1. Go to [Railway](https://railway.app)
2. Click "New Project" → "Deploy from GitHub repo"
3. Select your forked repository

### Step 2: Add PostgreSQL Database

1. In your Railway project, click "New"
2. Select "Database" → "Add PostgreSQL"
3. Railway will automatically create a `DATABASE_URL` variable

### Step 3: Configure Environment Variables

Add the following environment variables in Railway:

**Required:**
- `DATABASE_URL` - Auto-generated by Railway PostgreSQL
- `HUGGINGFACE_TOKEN` - Your Hugging Face API token ([Get one here](https://huggingface.co/settings/tokens))

**Optional:**
- `HF_MODEL_ID` - Hugging Face model ID (default: `meta-llama/Llama-3.3-70B-Instruct`)
- `NEXT_PUBLIC_BASE_URL` - Your Railway app URL (e.g., `https://your-app.railway.app`)

**Alternative LLM (if not using Hugging Face):**
- `OPENAI_API_KEY` - OpenAI API key
- `OPENAI_BASE_URL` - OpenAI API base URL (default: `https://api.openai.com/v1`)
- `OPENAI_MODEL` - OpenAI model name (default: `gpt-4o-mini`)

### Step 4: Deploy

Railway will automatically:
1. Install dependencies
2. Run `prisma generate`
3. Build the Next.js app
4. Run database migrations (`prisma migrate deploy`)
5. Start the server

**Note**: The start command now automatically applies database migrations before starting the server, so no manual migration step is needed after deployment.

## 📝 API Endpoints

- `GET /api/health` - Health check
- `POST /api/rooms` - Create a new room
- `GET /api/rooms/[id]` - Get room details
- `POST /api/rooms/[id]/cards` - Pick a card
- `DELETE /api/rooms/[id]` - Delete room (requires `x-host-token` header)
- `PATCH /api/rooms/[id]/cards/[cardId]` - Hide card (requires `x-host-token` header)

## 🗄️ Database Schema

```prisma
model Room {
  id          String   @id @default(cuid())
  question    String
  hostToken   String   @unique
  createdAt   DateTime @default(now())
  expiresAt   DateTime
  cards       Card[]
}

model Card {
  id          String   @id @default(cuid())
  roomId      String
  cardType    String
  nickname    String?
  reading     String
  isHidden    Boolean  @default(false)
  createdAt   DateTime @default(now())
  room        Room     @relation(fields: [roomId], references: [id])
}
```

## 🤖 LLM Integration

The app uses a 3-tier LLM strategy:

1. **Primary**: Hugging Face Inference API (recommended, free tier available)
2. **Fallback**: OpenAI-compatible API
3. **Final Fallback**: Deterministic Korean templates (no API key needed)

### System Prompt
```
카드 = 관계 역할 메타포만. 2인칭.
출력: (1) 훅 (2) 위치·역할 2문장 (3) 캡션
금지: 운세·예언·비하·실명추정
```

## 🎯 User Flow

1. **Host** creates room with a question → gets shareable URL
2. **Visitors** access URL → pick 1 of 12 metaphor cards
3. **LLM** generates 2nd-person reading based on card & question
4. **All users** see all picked cards on the same URL
5. **Host** can delete room or hide specific cards
6. **Auto-expiry** after 7 days

## 🔒 Privacy

- No login required
- Collected data: question, selected card, nickname (optional)
- Rooms automatically expire after 7 days
- Host can delete room anytime with host token
